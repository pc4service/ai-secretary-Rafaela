# Πρότυπο: Υπενθύμιση πληρωμής / χαμηλού υπολοίπου

**Tags:** email, billing, payment, reminder, finance  
**Γλώσσα:** EL  

## Σκοπός
Ευγενική υπενθύμιση για εκκρεμή πληρωμή ή ανανέωση υπηρεσίας.

## Πρότυπο

```
Θέμα: Υπενθύμιση — [Υπηρεσία / λογαριασμός] 

Αγαπητέ/ή [Όνομα],

Θέλουμε να σε ενημερώσουμε ότι [περιγραφή: π.χ. το υπόλοιπο του λογαριασμού Χ είναι χαμηλό / εκκρεμεί τιμολόγιο #…].

Λεπτομέρειες:
• Λογαριασμός / αναφορά: […]
• Ποσό / κατάσταση: […]
• Προθεσμία: […]

Για διευθέτηση: [link ή οδηγία].
Αν ήδη εξοφλήθηκε, αγνόησε αυτό το μήνυμα ή απάντησε για επιβεβαίωση.

Είμαστε στη διάθεσή σου,
[Ομάδα / Όνομα]
```

## Οδηγίες προς Rafaela
- Τόνος ήπιος, όχι απειλητικός.  
- Αν η πηγή είναι εισερχόμενο alert (π.χ. telco/pbx), σύνοψε πρώτα το alert και μετά πρότεινε draft.
