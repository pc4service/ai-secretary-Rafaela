# Πρότυπο: Introductory email σε νέο πελάτη

**Tags:** email, intro, onboarding, πελάτης, first-contact  
**Γλώσσα:** EL / EN  

## Σκοπός
Πρώτη επαφή μετά από lead, εισαγωγή ή παραπομπή.

## Πρότυπο (EL)

```
Θέμα: Χαίρομαι για την επικοινωνία μας — [Εταιρεία / θέμα]

Αγαπητέ/ή [Όνομα],

Είμαι η/ο [Όνομα], [ρόλος] στην [Εταιρεία]. Με χαρά επικοινωνώ μαζί σου σχετικά με [θέμα / ανάγκη].

Πώς μπορούμε να βοηθήσουμε:
• [Όφελος / υπηρεσία 1]
• [Όφελος / υπηρεσία 2]

Προτείνω μια σύντομη κλήση [15–20'] για να καταλάβουμε καλύτερα τις προτεραιότητές σου.
Διαθεσιμότητα από μέρους μου: [ημέρες/ώρες] (Europe/Athens).

Με εκτίμηση,
[Όνομα]
```

## Πρότυπο (EN)

```
Subject: Great to connect — [Company / topic]

Hi [Name],

I'm [Name], [role] at [Company]. I'm reaching out regarding [topic/need].

How we can help:
• [Benefit 1]
• [Benefit 2]

Would a short 15–20 min call work this week? I'm available [slots] (Europe/Athens).

Best regards,
[Name]
```

## Οδηγίες προς Rafaela
- Κράτα μήκος < 150 λέξεις.  
- Ζήτα ρητά 1 next step (call / demo / απάντηση).  
- Μην υπερβάλλεις σε υποσχέσεις προϊόντος.
