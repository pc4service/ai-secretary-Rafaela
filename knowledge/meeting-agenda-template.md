# Πρότυπο: Agenda συνάντησης

**Tags:** meeting, agenda, προετοιμασία, calendar  
**Γλώσσα:** EL  

## Σκοπός
Agenda πριν από internal ή πελατειακή συνάντηση.

## Πρότυπο

```
# Agenda — [Τίτλος]
**Ημερομηνία/ώρα:** [ISO ή τοπική] (Europe/Athens)  
**Διάρκεια:** [π.χ. 30']  
**Συμμετέχοντες:** [ονόματα]  
**Στόχος συνάντησης:** [1 πρόταση]

## Θέματα
1. [5'] Check-in / context  
2. [10'] [Κύριο θέμα Α]  
3. [10'] [Κύριο θέμα Β / αποφάσεις]  
4. [5'] Next steps & owners  

## Προετοιμασία
- [ ] [Υλικό / doc προς ανάγνωση]
- [ ] [Αριθμοί / status προς ενημέρωση]

## Επιθυμητά outcomes
- [Απόφαση 1]
- [Owner + deadline]
```

## Οδηγίες προς Rafaela
- Αν υπάρχει calendar event, ευθυγράμμισε τίτλο/ώρα.  
- Πρότεινε ρεαλιστικούς χρόνους ανά slot.  
- Ρώτα αν λείπουν participants ή στόχος.
