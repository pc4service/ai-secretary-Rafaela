# Orchestration defaults

Markdown contracts for multi-agent work on Rafaela.

## Files

| File | Purpose |
|------|---------|
| ORCHESTRA.md | Routing, gates, acceptance |
| ROLES.md | Paste-ready role prompts |
| PLAYBOOKS.md | Standard flows |
| HANDOFF.md | Agent-to-agent handoff template |
| PLAN.md | Current objective |
| STATUS.md | Live board |
| DECISIONS.md | Decision log |

## Quick start

1. User states goal.
2. Orchestrator pane: load ROLES.md Orchestrator block + update PLAN.md.
3. Open specialist panes; paste matching ROLES.md blocks.
4. Specialists read PLAN.md and write results + STATUS.md.
5. Orchestrator closes the loop for the user.

## Rules pointer

Product and safety rules live in ../../AGENTS.md and ../../CLAUDE.md.
If this folder conflicts with AGENTS.md, AGENTS.md wins.
